# VK-mini-app-API

API для VK mini app.

Этот репозиторий теперь имеет аккуратный README, который можно использовать как витрину проекта: описание сервиса, ссылки на документацию и базовые шаги для запуска удобно держать именно здесь.

## Что обычно важно указать

- назначение API;
- какие данные оно обслуживает;
- как настроить окружение;
- как запустить сервис локально;
- где смотреть Swagger/OpenAPI или примеры запросов.

## Быстрый старт

1. Склонируйте репозиторий.
2. Установите зависимости.
3. Запустите API и проверьте интеграцию с mini app.
